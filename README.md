# おおくぼ内科クリニック 更新ダッシュボード

おおくぼ内科クリニックの本番HPを更新するためのGitHub Pages用ダッシュボードです。

## 編集できる範囲

- TOPのトピックス
- 医院案内ページ下部の診療報酬のお知らせ

変更内容はブラウザの `localStorage` に下書き保存され、同じブラウザ内の確認プレビューへ反映されます。公開確認サイト側はこの下書きを読まず、GitHub Pagesで公開済みのデータだけを表示します。
公開変更は `makoban` のGitHubログイン確認を経由し、サイト側のGitHub Actionsが内容を検証して公開データを更新します。

反映先はさくらの本番HP `https://www.okubo-naika-cl.com/` です。「本番HPに公開する」→GitHubの所有者アカウントで送信確定後、検証済みの公開データをさくらが自動取得します。本番のデータ一致が確認されたときだけ、Issueに完了コメントが付き閉じられます。未確認・失敗時は開いたまま残ります。PCの常時起動や手動アップロードは不要です。

本番の内容は短時間キャッシュされます。GitHub側の通信に失敗した場合は直前の正常な公開内容を維持します。編集中に別の公開があった場合は上書きを拒否するため、最新の公開内容を読み直して変更を確認してください。更新専用のサーバーパスワードやGitHubトークンをブラウザへ渡す仕組みはありません。

本番HP: <https://www.okubo-naika-cl.com/>

操作説明書: <https://makoban.github.io/okubo-naika-dashboard/manual.html>

## 回帰テスト

追加パッケージは不要です。Node.jsの標準テストランナーで実行します。

```bash
node --test tests/*.test.mjs
```

ブラウザ下書きの保存・判定・リセット、安全な別画面表示、CMSの件数・文字数上限を検査します。
